# תיק משתמש - TeamInsight
## מערכת ניטור וניתוח פרויקטים צוותיים

---

## הסבר כללי על המערכת

**TeamInsight** היא פלטפורמה מתקדמת לניטור ובחינת בריאות צוותי פרויקט. המערכת פותחה כדי לתת מענה לצרכים של מרצים המלווים צוותי סטודנטים בפרויקטים, ומאפשרת מעקב שוטף אחר התקדמות הצוותים, זיהוי בעיות מוקדם וקבלת תובנות מבוססות AI.

### מטרות המערכת:

1. **ניטור מתמשך**: מעקב אחר מצב הצוותים לאורך הסמסטר באמצעות רפלקציות שבועיות
2. **ניתוח דינמיקה צוותית**: זיהוי דפוסים התנהגותיים וניתוח לפי מודל Tuckman
3. **Team Health Score (THS)**: ציון בריאות צוות מבוסס AI (0-100)
4. **התראות אוטומטיות**: זיהוי צוותים במצב סיכון ושליחת התראות למרצה
5. **שיחת רפלקציה מונחית**: צ'אטבוט AI שמנחה את הצוות בתהליך רפלקציה שבועי

### טכנולוגיה וחדשנות:

1. **מודל AI מתקדם**: שימוש ב-Cerebras Cloud SDK עם מודל Llama-3.3-70b
2. **ניתוח Team Health Score**: הערכה רב-ממדית של בריאות הצוות
3. **מסד נתונים**: MongoDB Atlas לשמירת כל הנתונים
4. **ממשק משתמש מודרני**: Next.js 16 + React 19 + Tailwind CSS

| אלמנט | תיאור |

### 8. ניתוח רפלקציה (Team Reflection Analysis)

```
נתיב: /lecturer/teams/[teamId]/chat
```

מסך מפורט לניתוח הרפלקציה של הצוות.

**בחירת Session**: dropdown לבחירת סשן ספציפי.

**לשוניות**:

#### לשונית Analysis (📊):

| רכיב | תיאור |
|------|--------|
| **Team Health Score** | ציון כולל 0-100 |
| **Risk Level** | רמת סיכון 0-10 |
| **Tuckman Stage** | שלב התפתחות הצוות |
| **THS Components** | 4 מרכיבי הציון |

**מרכיבי THS**:
| מרכיב | משקל | תיאור |
|-------|-------|--------|
| Participation Equity | 25% | שוויון השתתפות |
| Constructive Sentiment | 15% | טון חיובי/שלילי |
| Reflective Depth | 40% | עומק הרפלקציה |
| Conflict Resolution | 20% | יכולת פתרון קונפליקטים |

**Anomaly Flags (התראות)**:
- 🔴 אזור אדום - THS נמוך
- 🔇 חבר צוות שותק
- ☠️ זינוק בשליליות
- 🔁 בעיה כרונית

**תובנות**: חוזקות, חששות, המלצות.

#### לשונית Chat (💬):

צפייה בשיחה המלאה בין הצוות ל-AI.

## רשימת טעויות אפשריות

### 1. שגיאות התחברות

| שגיאה | סיבה | פתרון |
|-------|------|--------|
| "Login failed" | אימייל או סיסמה שגויים | בדקו את הפרטים והקלידו שוב |
| "Invalid credentials" (צוות) | Team ID או Access Code שגויים | בקשו מהמרצה את הפרטים הנכונים |
| "Network error" | בעיית חיבור לשרת | בדקו את חיבור האינטרנט ונסו שוב |
| "Server error" | תקלה בשרת | המתינו מספר דקות ונסו שוב |

### 2. שגיאות בצ'אטבוט הרפלקציה

| שגיאה | סיבה | פתרון |
|-------|------|--------|
| "לא הצלחתי להתחיל רפלקציה כרגע" | בעיה בחיבור ל-AI | לחצו על "איפוס" ונסו שוב |
| "משהו השתבש. נסו שוב בעוד רגע" | תקלה בשליחת ההודעה | המתינו ונסו לשלוח שוב |
| הצ'אטבוט איטי | זמן תגובה ארוך של ה-AI | זו התנהגות תקינה - המתינו לתשובה |

### 3. שגיאות ביצירת צוות

| שגיאה | סיבה | פתרון |
|-------|------|--------|
| "Please fill Team ID, Project Name..." | שדות חובה חסרים | מלאו את כל השדות הנדרשים |
| "Member ID must be unique" | מזהה חבר כפול | השתמשו במזהה אחר |
| "Failed to create team" | Team ID כבר קיים | בחרו מזהה צוות אחר |

### 4. שגיאות בהעלאת CSV

| שגיאה | סיבה | פתרון |
|-------|------|--------|
| "Please select a CSV file" | לא נבחר קובץ | לחצו על "Choose File" ובחרו קובץ |
| "CSV upload failed" | פורמט קובץ שגוי | ודאו שהקובץ בפורמט CSV תקין |

### 5. בעיות נפוצות בשימוש

| בעיה | סיבה | פתרון |
|------|------|--------|
| הנתונים לא מתעדכנים | cache בדפדפן | לחצו על כפתור "Refresh" במסך |
| לא רואה צוותים/התראות | אין נתונים במערכת | ודאו שיצרתם צוותים/יש התראות |
| הגרפים ריקים | אין מספיק נתונים | המתינו שצוותים יגישו רפלקציות |
| לא מצליח להגיש רפלקציה | הסשן לא מוכן | המשיכו את השיחה עד שיופיע כפתור "הגשה" |

### 6. שגיאות ניווט

| בעיה | סיבה | פתרון |
|------|------|--------|
| "Team not found" | Team ID לא קיים | בדקו שה-URL נכון |
| "No reflection session found" | הצוות עדיין לא התחיל רפלקציה | המתינו שהצוות יתחיל את הרפלקציה |
| "No sessions" ב-dropdown | אין סשנים לצוות זה | הצוות צריך להתחיל רפלקציה |

## טיפים לשימוש יעיל

### למרצים:

1. **בדקו את דשבורד ההתראות באופן קבוע** - צוותים באדום דורשים תשומת לב
2. **השתמשו בפילטרים באנליטיקות** - ניתן לראות צוות ספציפי או לסנן לפי סטטוס
3. **פרסמו הודעות שבועיות** - תזכורות לצוותים להגיש רפלקציה
4. **הגדירו הנחיות שבועיות** - ב-Reflection Settings ניתן לכוון את ה-AI

### לצוותים:

1. **ענו בפירוט** - ככל שהתשובות מפורטות יותר, הניתוח יהיה טוב יותר
2. **השתמשו ב-Shift+Enter** - לשורה חדשה בתוך התשובה
3. **אל תסגרו את הדפדפן** - השיחה נשמרת, אבל עדיף לסיים בישיבה אחת
4. **בדקו הודעות** - המרצה עשוי לפרסם עדכונים חשובים
